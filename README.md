# 繁梅字體 / Fanmei Fonts

基於[「梅系列字體 / Ume Fonts」](https://zh.osdn.net/projects/ume-font/)的輕量增補專案。

[![0BSD](https://img.shields.io/github/license/lxgw/Fanmei)](https://github.com/lxgw/Fanmei)

![image](./image.png)

## 簡介

「繁梅字體 / Fanmei Fonts」為「梅系列字體 / Ume Fonts」的貢獻性增補專案，包含「繁梅黑體 / Fanmei Hei」及「繁梅明體 / Fanmei Ming」兩款字型，分別基於「梅ゴシック / Ume Gothic」與「梅明朝 / Ume Mincho」進行輕量增補與調整。

本專案增補 BIG5 常用字、注音符號及蘇州碼子，調整少量具有明顯日式風格的字形（如<span lang="ja">「僧」「抱」「漢」「耀」</span>等），並新增 950 代碼頁支援。此外，將 U+005C 碼位原有的 `¥` 符號調整為 `\`，調整標點符號為置中，並將半寬方塊繪製字元、箭頭、部分幾何圖形符號及雜類符號改為全寬，以符合繁體中文的使用習慣。

標點符號調整過程中被替換下來的原有符號，收錄於「小型標點變體」區塊，亦可透過 Unicode 標準變體序列（SVS）調用（例如<span lang="zh-tw">「，」</span>預設為置中，加入變體選擇符 `U+FE00` 後則改為左下角，更多支援序列參閱[此處](./uvs.pdf)）；漢字調整過程中被替換下來的日式風格字形，則可透過 `locl` 特性於日文環境下調用。

## 注意事項

- 本字型目前僅增補 BIG5 常用字，後續可能會視情況增補 [「jf7000 當務字集」](https://justfont.com/jf7000) 的基本包及粵語擴充包，目前沒有進一步增補字形的計劃。
- 簡中版的工程量與本專案的輕量補繁工作不在同一個量級，因此亦無計劃製作簡中版。原因如下：
  - 僅補全 GB 2312 一級字（3,755 字），在此範圍內原字體（不計繁梅已增補字形）僅包含 2,643 字，需額外增補上千字；
  - 原字體從未包含簡化字獨有部件，需從零製作；
  - 大量已有字形需按照簡中標準字形逐一調整（「梅系列字體」雖有學參版，但能直接採用的比例很低）。
- 本字型調整漢字以 BIG5 常用字為限，調整對象僅限有明顯日式風格的字形。除辵部、戶部、示部、食部等少數觀感上需要統一的部首外，其餘部件保留多樣性，不強求各部件完全一致，並遵循 Unicode「字源分離」原則（如「值/値」「巔/巓」「飲/飮」等字的差異予以保留）。
- 為維持字型風格的一致性與維護效率，本字型僅提供等寬版，便於程式碼、表格等排版場景使用，不提供比例寬版。
- 本專案目前並無持續維護的計劃，但不排斥後續視情況修正。如有問題，可嘗試透過 Issue 提出，惟不保證一定回應或處理。
