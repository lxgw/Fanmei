# 繁梅字體 / Fanmei Fonts

基於[「梅系列字體 / Ume Fonts」](https://zh.osdn.net/projects/ume-font/)的 BIG5 常用字貢獻性補全專案。

## 簡介

「繁梅字體 / Fanmei Fonts」為「梅系列字體 / Ume Fonts」的貢獻性增補專案，包含「繁梅黑體 / Fanmei Hei」及「繁梅明體 / Fanmei Ming」兩款字型，分別基於「梅ゴシック / Ume Gothic」與「梅明朝 / Ume Mincho」進行擴充。

本專案增補 BIG5 常用字、注音符號及蘇州碼子，並新增 950 代碼頁支援。此外，將 U+005C 碼位原有的 `¥` 符號調整為 `\`，並將半寬方塊繪製字元改為全寬。其餘字圖則暫未更動。

## 注意事項

- 本字型暫無進一步增補字形的計劃，亦無計劃製作簡中版。
- 本字型目前僅增補 BIG5 常用字，未對「梅ゴシック」「梅明朝」原有字圖進行修改。後續可能會以 BIG5 常用字為限，按照繁中慣用字形調整部分漢字字圖，並試圖修正原始字型含有的如下問題。如有調整將在更新說明中註明。

### 原始字型已知問題
- [x] ~~部分方塊繪製字元為半寬。~~
- [ ] 部分箭頭、幾何圖形字元為半寬。
- [ ] 梅黑體「淴」右部誤作「怱」。
- [ ] 梅黑體「箰」在顯示為明體。
- [ ] 梅黑體「舔」的「舌」為明體。
